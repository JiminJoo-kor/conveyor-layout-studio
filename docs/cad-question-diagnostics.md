# 도면 질문과 상세 진단

CAD 분석 후 설비 분류 불명, 치수·단위 확인, 설비별 인계 흐름, 도면 경고를 질문으로 만든다. 각 질문은 원본 엔티티 인덱스·레이어·블록·CAD 좌표·추정 치수 및 근거를 보존한다. 도면 일부 이미지는 변환된 선을 중심 위치 주변에서 렌더링한 참고 이미지이며, 원본 CAD 화면을 완전히 재현하는 캡처가 아니다. 변환 누락·실패 시 원본 PNG/JPEG/WebP 캡처를 질문별로 첨부할 수 있다(각 5MB 이하).

질문은 8개씩 표시하며 페이지 밖 질문까지 모든 답변이 공백이 아니어야 HTML/JSON 진단을 저장할 수 있다. “모르겠음”, “미확인” 등은 답변 완료로 인정하되 미해결 목록에 남긴다. HTML은 이미지와 질문·답변을 함께 보는 로그, JSON은 이미지와 구조화된 분석 근거를 전달하는 자료다. 파일은 각각의 저장 버튼으로 다운로드하며 서버로 전송하지 않는다.

답변은 layout.cadQuestions에 저장되므로 레이아웃 JSON 내보내기에 포함된다. CAD 상태 영역의 “도면 질문 · 상세 진단”으로 다시 열 수 있다. 재분석 시 새 질문을 생성하므로 이전 결과가 필요하면 먼저 진단 또는 레이아웃을 저장한다.

자연어 답변을 설비·연결점 파라메터에 자동 적용하지 않는다. 이 로그를 검토해 분류·치수·연결·핸드셰이크의 변경안을 만들고 원본 대조 및 시뮬레이션으로 검증해야 한다. 모든 도면에 대한 무오류 자동 배치를 보장하는 기능은 아니다.
