# 서열렉 · 입고용 분배기 · 출고용 적재기

## 사용 방법

설비 추가에서 **서열렉 / 입고용 분배기 / 출고용 적재기**를 선택해 배치하고 기존 연결점 방식으로 연결합니다.

- 서열렉 → **스태커별 출고 상세 설정**: 독립 주기(시뮬레이션 초), 주기당 수량, FIFO / 시드 랜덤 / 지정 셀 순서. 모델리스 창에서 레이아웃을 함께 확인할 수 있습니다. 지정 셀은 `주행 열/단/행` 1-based 주소를 쉼표로 구분합니다. 설정 적용 시 시뮬레이션 초기화.
- 주기당 수량이 출고 스테이션의 1회 운반 용량보다 많으면 같은 작업으로 여러 번 운반합니다. 재고 부족 시 선택 가능한 수량만 처리합니다. 지정 순서의 빈 셀은 건너뛰지 않습니다. 정체 중 지난 주기를 몰아 실행하지 않습니다.
- 적재기 → **완성 적재 수량**, **들어올림/내려놓음 시간**, **최대 적재 높이**. 기본 수량 1. 같은 종류·규격의 빈 박스만 함께 적재합니다.
- 입고 설비 → **박스 1단 높이 / 빈 박스 여부**. 분배기가 있으면 **투입 적층 수량(단)**도 나타납니다. 기본은 빈 박스 1단입니다.
- 컨베이어 길이·속도·가감속·안전간격·연속 인계·허용 하중·신뢰성 옵션은 일반 컨베이어 파라미터를 사용합니다.

`examples/empty-box-stack-line.json`은 3단 입고 → 단품 분배 → 3단 재적재 → 출고 예제입니다.

## 실행 및 표시

- 입고 물품이 작업 위치에 완전히 들어온 뒤 승강 시작. 설비 길이가 물품 진행축 길이보다 짧으면 인수 금지.
- 적재: 새 박스 위에 보유 묶음을 내리고 전체를 들어 올려 대기. 목표 수량이면 하류 승인 후 배출.
- 분배: 맨 아래 1개를 남기고 나머지를 들어 올림. 단품 인계 완료 후 나머지를 내려 반복.
- 배출은 기존 컨베이어 엔진이 담당. 경계 걸침·수신 중에는 스토퍼 복귀와 다음 묶음 인수 금지.
- 고장/비가동 시 승강 정지. 묶음 중량과 누적 높이 검사. 표시 배율은 물리적 간격 계산에 사용하지 않음.
- 레이아웃: 적층 선·개수, 스토퍼 상태, 보유/목표 수량, 잔여 %, 승강 확대/축소 표시. 인계 중에도 적층 개수 유지.
- 완료 기록에 개별 박스 ID·규격·중량·종류·순서 보존. 완료 표시는 묶음/박스 구분, WIP는 들고 있는 박스 포함. UPH는 기존 완료 물류(묶음) 기준.
- 서열렉의 셀 이동·입출고 스테이션·3D LIVE는 기존 AS/RS 동작 공유. 주기와 순서 커서는 스태커별 독립이며 실제 출고 스테이션 인계 완료에서 갱신.
- 진단 TXT에 적재/분배 단계·보유 수량·스토퍼와 독립 출고 작업 추가.

## 저장 및 호환

JSON은 기본 `type`을 `conveyor`/`asrs`로 유지하고 `equipmentRole`에 `boxStacker`/`boxDestacker`/`sequenceRack`을 저장합니다. 기존 연결점·시퀀스·핸드셰이크 코드를 공유하며 프로젝트 이름이나 색상으로 동작을 구분하지 않습니다. 잘못된 수량·시간·셀 범위는 실행 검증에서 차단합니다.

## 검증

- 기존 회귀 테스트와 신규 순수 제어/실제 엔진/렌더링 테스트.
- 실제 분배→적재 경로의 박스 ID 보존 및 배속 불변성.
- 하류 차단/재개, 승강 중 비가동, N=1/N=8, 하중/규격 불일치, stale ACK, 독립 출고 주기·지정 셀 및 다회 운반.
- 상하좌우 회전의 유효한 표시 좌표와 바닥 박스/들린 묶음 분리.
- 브라우저에서 설비 추가, 상세 설정 적용·재열기, 예제 JSON 실행과 적층 상태 표시 확인.
- 사용자 기존 91설비 JSON 사본으로 120초 엔진 실행 확인. 모든 장시간 운전 시나리오를 보증하는 검사는 아닙니다.
