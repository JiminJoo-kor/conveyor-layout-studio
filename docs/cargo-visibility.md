# 긴 설비의 물류 가시성

레이아웃 아래 **물류 상세 보기**를 열고 설비를 선택합니다.

- 전체 화면: 작은 물류에 원형 위치 표식을 표시합니다. 가까운 표식은 고유 물류 ID 기준으로 묶어 수량을 표시합니다. 원형은 상자의 실제 외곽이 아닙니다.
- 상세창: 입구, 출구, 중간 구간 슬라이더 또는 선택 물류 따라가기를 사용합니다. 확대 배율은 원본 물류와 간격에 동일하게 적용됩니다.
- 컨베이어의 전체 길이 대비 현재 확대 구간을 mm 거리와 막대로 표시합니다. 이동 중에는 진행 방향 앞쪽을 넓게 보여주고 같은 설비 내 자동 추적은 부드럽게 이동합니다.
- **위치·배율 고정**을 켜면 물류가 이동해도 카메라는 유지됩니다. 설비·보기·물류·배율을 직접 바꾸면 고정은 해제됩니다.
- **인계 양단 자동 보기**는 원본 렌더러가 인계 중으로 판단한 물류의 상류 출구와 하류 입구를 별도 화면으로 표시합니다. 설비명과 인계 진행률을 함께 표시하며 화면 사이 거리는 실제 거리와 무관합니다. 위치 고정 중에는 양단 자동 전환을 하지 않습니다.
- 물류 번호를 선택하면 같은 ID가 다음 설비로 넘어가도 표시 위치를 따라갑니다. 내부 저장 등 원본에서 표시되지 않는 단계에는 해당 설비와 내부 작업 안내를 표시하며, 가상의 물류 위치를 만들지 않습니다. AS/RS 셀 내부 작업은 3D LIVE로 확인합니다.
- 내부 스테이션과 AMR/AGV도 기존 렌더러의 인계·이동 표현을 그대로 재사용합니다. 상세창은 기구 상세 도면이 아니라 기존 레이아웃의 국소 확대입니다.

치수, 안전간격, 물리 엔진, 핸드셰이크, UPH 계산 및 JSON 데이터는 변경하지 않습니다. 상세창은 열려 있을 때 최대 초당 10회 갱신하고 고정 크기 캔버스를 재사용합니다(기본 1개, 인계 양단 보기 시 최대 2개). 과거 프레임이나 물류 이력을 별도로 누적하지 않습니다.

자동 검증: `node --test test/cargo-visibility.test.js`

브라우저 검증: 로컬 서버에서 `/test/cargo-visibility-browser.html`. 5,500m 컨베이어 위 1.2 × 0.8m 물류 두 개의 0.2m 간격을 확인할 수 있는 정지 장면입니다.
